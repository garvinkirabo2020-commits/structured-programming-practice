Structured Programming Practice

CSC1101 – Structured Programming

This repository contains eight C programming exercises completed for the Structured Programming GitHub Practice Assignment.

Programs Included

1. Basic Output – Displays simple information using printf().
2. Input–Process–Output – Takes user input and calculates the area of a rectangle.
3. Decision – Uses if, else if and else to determine whether a number is positive, negative or zero.
4. Basic Loop – Uses a for loop to display numbers from 1 to 10.
5. Loop with Calculation – Uses a loop to calculate the sum of numbers from 1 to 10.
6. Loop with User Input – Accepts five numbers from the user and calculates their total.
7. Loop with Decision – Uses a loop and if/else to identify even and odd numbers.
8. Interactive Console – Provides a simple menu that allows the user to check numbers or exit.

Concepts Covered

* printf() and scanf()
* Variables and arithmetic
* if, else if, else
* for loops
* do...while loops
* User input
* Decision making
* Basic menu-driven programs
   Textbook Reference

The exercises are based on concepts from C How to Program, 9th Edition by Paul Deitel and Harvey Deitel. Specific chapter and exercise references are included where required by the assignment.

Testing

All programs should be compiled and tested before submission to make sure they run correctly and demonstrate the required programming concepts.

Conclusion

This project demonstrates the basic principles of structured programming in C through eight simple practical programs.
